実施率・成約率はなぜ下がったのか、どう直すか

対象期間 2026/4/1–8/31（5ヶ月・全1,601名）｜対象 LSTEP 3口座（L1／L2／L3）｜データ基準日 2026/9/3｜ミーティング用

0. 結論（3行）

  • 実施率が下がったのは「当日キャンセル」が増えたからです。事前キャンセルは横ばい（約15%）なのに、当日キャンセルだけが 19% → 29% と毎月増え続けています。特にL3では予約の半分以上が消えています。根拠：【予定日】4–8月
  • 成約率が下がったのは「流入元が入れ替わった」からで、担当個人の問題ではありません。4月に予約の37%を占めていた質の高い流入（ASP・LP名なし：成約率27%）が8月は6%に消え、代わりにアフィリエイトLP経由が85%に。そのLPの質もばらつき、質の低いLPが7–8月を占めています。担当7名中6名が同時に落ちたのはそのためで、担当構成の影響は−2pt程度です。根拠：【予定日】4–5月 vs 8月
  • 直せます。面談LT・申込→予約の歩留まりは悪化していないので、入口は壊れていません。実施率と成約率は同じ原因（見込み度の低い申込者の増加）から来ているので、①予約前の意思確認と当日キャンセル対策 ②流入元別の切り分け ③主力2名のレビューと優先度の傾斜 で、月あたり実施+15件・成約+9件が概算で取り戻せます。

3. どうして成約率が下がったのか 【予定日】

まず切り分け：「人が変わった」のか「決められなくなった」のか

担当構成だけが8月に変わった場合29.7%4–5月 32.0% → 構成効果 ▼2.3pt
担当ごとの率だけが8月に変わった場合21.5%4–5月 32.0% → 率効果 ▼10.4pt

構成の影響は小さく、「同じ担当が決められなくなった」効果がほぼすべてです。しかもそれが特定の1〜2名ではなく、両期間で実績のある7名中6名で同時に起きています（下表）。全員が同時に落ちるのは技術の問題ではなく、面談に来る人の見込み度が下がったサインです。

理由2：決まりやすいL2が消え、決まりにくいL3の比重が増えた

実施の階層構成は 4–5月「L1 61%／L2 11%／L3 29%」→ 8月「L1 62%／L2 0%／L3 38%」。成約率44%のL2がゼロになり、L3は比重が増えたうえに自身の成約率も15%へ低下（33実施で5成約）。階層構成の効果は約-1.4ptで、担当構成より大きい。

理由3（副次的）：主力2名の不調と、決められる人の担当縮小

  • 加藤 建志さん（実施シェア1位）36.4% → 16.7%、水野 達也さん（同2位）28.8% → 18.2%。全体傾向の一部ではありますが、2名で8月実施の26%を占めるため絶対件数への影響が最大。加藤さんは他PJでも同時に低下しており、本人要因も併存します。
  • 渡邉 巧巳さん（成約率50%・4–5月46件）が8月は4件。L1では14名が優先度1で横並びのため、自動振り分けが薄く分散しています。構成効果としては−2pt程度ですが、設定変更だけで取れる分です。

原因ではないもの

  • クロージングの遅さではありません。実施→成約は 10.8日 → 4.8日 とむしろ速くなっています。決まる人は早く決まり、決まらない人が増えた、という構図です。

4. どうしたら改善できるのか（優先度順・効果測定つき）

実施率と成約率は同じ原因から来ています。入口（見込み度）を直せば両方が同時に戻り、担当への打ち手だけでは戻りません。順番はこの通りに。

優先度1 予約の前に「本気度」を一段確認する（実施率・成約率の両方）

  • 予約確定時に参加意思を1ステップ確認する（日程確定の返信必須、または短い事前質問）。返信のない予約は確定扱いにしない。
  • 前日リマインドに返信を求め、返信がなければ当日朝に確認。返信なし＝キャンセル扱いにして枠を空ける。
  • 8/29に新設した「審査フォーム統合」カレンダーはまさにこの導線変更です。9月の当日キャンセル率と成約率で効果を検証し、効けばL3にも展開する。
  • L3は予約数より見込み度を優先してよい段階です（予約の半分が消え、来ても15%しか決まらない）。

効果測定：【予定日】の当日キャンセル率（目標 29% → 20%）と成約率（目標 22% → 30%）。両方が動けば原因の見立てが正しかったことになります。

優先度2 流入元を絞る（原因そのものへの対処）

  • 「ASP・LP名なし」の流入が7月以降ほぼ止まった理由を確認する。この層は予約の37%・成約率27%の主力でした。広告停止・LP変更・ASP設定の変更など、意図した変更か事故かをまず特定する。戻せるなら戻すのが最優先。
  • 質の低いアフィリエイトLPに条件を付ける。当日キャンセル30%超または成約率20%以下のLP（上表）は、単価の見直し・配信停止・事前確認の強化の対象。7–8月の予約の多くがここから来ています。
  • 質の高いLP（LP146・LP657・LP385など）の配信を増やす。実施率70〜80%・成約率50%超で、月に数件しか来ていない。ここに予算を寄せる。

効果測定：流入元区分別の【予定日】実施率・成約率・当日キャンセル率（月次）。「ASP・LP名なし」の予約シェアと、質の低いLPのシェアを追う。

優先度3 加藤さん・水野さんの同席レビュー、優先度の傾斜、平日夜枠の見直し

原因は入口側でも、この2名で8月実施の26%を占めるため、戻せば件数への効果は最大です。同時に、L1の優先度1が14名横並びなのを直近成約率で3段階に傾斜させます（渡邉・林・白土・池本を優1／加藤・水野・若松を優2／藤井・竹本・今村を優3）。構成効果は−2pt分ですが設定変更だけで取れます。

あわせて平日夜の枠（実施率42%）は縮小し、土日・水木に寄せる。予約リードが翌日以内の予約は予約当日に確認連絡を入れる。

効果測定：【結果】の本人成約率（加藤さん 17%→30%、水野さん 18%→28%）、渡邉さんの実施シェア（4.5%→15%以上）、平日夜枠の【予定日】実施率。

優先度4 L2の導線を確認する

成約率44%と最も決まりやすい階層の予約が、4月41件→8月0件。意図した停止か、導線が切れているかを確認してください。切れているなら復旧だけで成約率が上がります。

効果測定：【申込日】のL2申込件数（月次）。

別件 集客減（予約379→164件）

本レポートの範囲外ですが、率を直しても件数が戻らなければ成約数は戻りません。優先度2の流入元分析と同じ作業で扱えます。
